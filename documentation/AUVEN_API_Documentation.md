## 1. Project Overview
AUVEN Fashion is a customisable T-Shirt clothing brand running on a MERN full-stack architecture. This document provides an exhaustive reference for all the backend REST APIs actually implemented in the system.

---

## 2. Architecture Overview
- **Backend Framework:** Node.js with Express.js
- **Database:** MongoDB (using Mongoose ODM)
- **Authentication:** JSON Web Tokens (JWT)
- **File Uploads:** Multer & Cloudinary
- **Payments:** Stripe API & Cash On Delivery
- **Routing:** Express Router

---

## 3. Backend Data Model Overview
The backend uses Mongoose to interact with MongoDB. 

- **userModel:** Stores `name`, `email`, `password`, `cartData` (JSON object), and an array of `addresses`.
- **productModel:** Stores product `name`, `description`, `price`, `image` (array), `category`, `subcategory`, `sizes`, `inventory` array (size, colour, quantity), `bestseller`, and `date`.
- **orderModel:** Stores `userId`, `items`, `amount`, `address`, `status`, `paymentMethod`, `payment` boolean, `couponCode`, `discountAmount`, and `date`.
- **designModel:** Stores predefined customizer designs (`name`, `image`, `category`, `active`).
- **couponModel:** Stores discount codes (`code`, `discountPercentage`, `minimumOrderAmount`, `maximumDiscountAmount`, `expiryDate`, `active`).
- **homepageContentModel:** Stores dynamic UI configurations (`type`, `title`, `image`, `buttonText`, `productIds`, etc.).

## 5. Authentication
The application implements two distinct authorization levels: User and Admin.

- **User Authentication:** Requires a valid JWT token signed with `JWT_SECRET`. Token payload contains `{ id: user._id }`.
- **Admin Authentication:** Requires a token generated by signing `ADMIN_EMAIL + ADMIN_PASSWORD` with `JWT_SECRET`. 

**Middleware Used:**
- `authUser`: Validates JWT token from `token` header. Decodes it and appends `userId` to the request body.
- `adminAuth`: Validates JWT token from `token` header against the hardcoded Admin credentials.

## 7. Detailed API Documentation

### Authentication APIs

#### Register User
**Method:** POST
**Endpoint:** `/api/user/register`
**Description:** Registers a new user. Hashes the password and returns a JWT token.
**Authentication:** Not Required
**Authorization:** Public
**Headers:** None
**Path Parameters:** None
**Query Parameters:** None
**Request Body:**
```json
{
  "name": "John Doe",
  "email": "johndoe@example.com",
  "password": "strongpassword123"
}
```
**Success Response:**
```json
{
  "success": true,
  "token": "eyJhbGciOiJIUzI1..."
}
```
**HTTP Status:** 200 OK

#### User Login
**Method:** POST
**Endpoint:** `/api/user/login`
**Description:** Logs in an existing user and returns a JWT token.
**Authentication:** Not Required
**Authorization:** Public
**Request Body:**
```json
{
  "email": "johndoe@example.com",
  "password": "strongpassword123"
}
```
**Success Response:**
```json
{
  "success": true,
  "token": "eyJhbGciOiJIUzI1..."
}
```

#### Admin Login
**Method:** POST
**Endpoint:** `/api/user/admin`
**Description:** Logs in an admin by comparing credentials with env variables. Returns an admin JWT token.
**Authentication:** Not Required
**Authorization:** Public
**Request Body:**
```json
{
  "email": "admin@example.com",
  "password": "adminpassword"
}
```
**Success Response:**
```json
{
  "success": true,
  "token": "admin_jwt_token_here"
}
```

### User APIs (Customer)

#### Get Profile
**Method:** GET
**Endpoint:** `/api/user/profile`
**Description:** Retrieves the logged-in user's profile information (excludes password).
**Authentication:** Required
**Authorization:** User
**Headers:**
| Header | Required | Description |
|--------|----------|-------------|
| token | Yes | User JWT Token |

**Success Response:**
```json
{
  "success": true,
  "user": {
    "_id": "648a1b2c3d...",
    "name": "John Doe",
    "email": "johndoe@example.com",
    "addresses": [],
    "cartData": {}
  }
}
```

#### Add Address
**Method:** POST
**Endpoint:** `/api/user/addresses`
**Description:** Adds a new shipping address to the user's profile. Automatically sets it to default if it is the first address or `isDefault` is true.
**Authentication:** Required
**Authorization:** User
**Request Body:**
```json
{
  "name": "Home",
  "phone": "9876543210",
  "addressLine1": "123 Main Street",
  "addressLine2": "Apt 4B",
  "city": "Chennai",
  "state": "Tamil Nadu",
  "postalCode": "600001",
  "country": "India",
  "isDefault": true
}
```
**Success Response:**
```json
{
  "success": true,
  "message": "Address added successfully",
  "addresses": [ { ... } ]
}
```

*(Note: Endpoints for Update Address, Delete Address, Set Default Address, Update Profile, and Change Password follow the identical structure utilizing the User ID provided via the `authUser` middleware).*

### Cart APIs

#### Add To Cart
**Method:** POST
**Endpoint:** `/api/cart/add`
**Description:** Adds a specific quantity of a standard product (variant) to the user's cart. Performs rigorous inventory validation to ensure requested quantity doesn't exceed available stock.
**Authentication:** Required
**Authorization:** User
**Request Body:**
```json
{
  "itemId": "60d21b46...",
  "size": "M",
  "quantity": 2
}
```
**Success Response:**
```json
{
  "success": true,
  "message": "Added To Cart"
}
```
**Error Response (Out of Stock):**
```json
{
  "success": false,
  "message": "Only 5 items are available for size M."
}
```

### Customizer APIs

#### Upload Customer Design
**Method:** POST
**Endpoint:** `/api/customizer/upload`
**Description:** Uploads a user-provided image (PNG, JPG, WEBP) to Cloudinary for custom T-Shirt printing. Maximum size: 5MB.
**Authentication:** Required
**Authorization:** User
**Headers:**
| Header | Required | Description |
|--------|----------|-------------|
| token | Yes | User JWT Token |
| Content-Type | Yes | multipart/form-data |

**Form Data:**
- `image`: File (Binary)

**Success Response:**
```json
{
  "success": true,
  "imageUrl": "https://res.cloudinary.com/.../uploads/custom1.png"
}
```

**Method:** POST
**Endpoint:** `/api/cart/addStandaloneCustomized`
**Description:** Adds a fully customized T-Shirt to the cart. Calculates dynamic pricing based on a base price + per-object pricing (Text/Design elements).
**Authentication:** Required
**Authorization:** User
**Request Body:**

```json
  "customKey": "custom_1694301234",
  "colour": "#FFFFFF",
  "quantity": 1,
```

**Success Response:**
```json

  "success": true,
  "message": "Customized T-Shirt Added To Cart"
```

### Order & Payment APIs

#### Place COD Order
**Method:** POST
**Endpoint:** `/api/order/place`
**Description:** Places an order via Cash On Delivery. Deducts inventory atomically to prevent race conditions. Applies coupons if valid.
**Authentication:** Required
**Authorization:** User
**Request Body:**
```json
{
  "items": [
    {
      "_id": "60d21b46...",
      "name": "Classic T-Shirt",
      "size": "M",
      "quantity": 2
    }
  ],
  "address": {
    "name": "Home",

    "addressLine1": "123 Street",
    "city": "Chennai",
    "state": "TN",
    "postalCode": "600001",
    "country": "India"
  },
  "couponCode": "SAVE20"
}
```
**Success Response:**
```json
{
  "success": true,
  "message": "Order Placed"
}
```

#### Place Stripe Order
**Method:** POST
**Endpoint:** `/api/order/stripe`
**Description:** Initializes a Stripe Checkout session. Automatically factors in dynamic product pricing, delivery fees, and generates on-the-fly Stripe coupons if a discount code is applied.
**Authentication:** Required
**Authorization:** User
**Success Response:**

```json
  "success": true,
  "session_url": "https://checkout.stripe.com/pay/cs_test_..."
```

#### Verify Stripe Payment
**Method:** POST
**Endpoint:** `/api/order/verifyStripe`
**Description:** Verifies the Stripe payment redirect. If successful, deducts inventory and marks order as paid.
**Authentication:** Required
**Authorization:** User
**Request Body:**
```json
{
  "orderId": "60d21b46...",

}
```

## 8. Error Handling
The API always returns a consistent JSON object structure upon error, maintaining an HTTP Status of 200 for graceful frontend interception.

**Common Error Structure:**
```json
{
  "success": false,
  "message": "Error description here"
}
```

**Common Errors Triggered:**
- **Authentication:** `"Not Authroized Login Again"`, `"Please login first to place order!"`
- **Validation:** `"Invalid email format"`, `"Password must be at least 8 characters long"`
- **Inventory/Cart:** `"Size is out of stock."`, `"Only X items are available for size Y."`
- **Uploads:** `"Image must be 5 MB or smaller."`, `"Unsupported image format."`

## 9. Postman Testing Guide

1. **Base URL Detection:**
   - Local: `http://localhost:4000` (or actual PORT defined in `.env`)
   - Production: Deployed URL (e.g., Render/Railway)

2. **Testing Sequence:**
   1. `POST /api/user/register` -> Copy `token`
   2. Paste `token` into Headers (`token: <your_token_here>`) for subsequent User routes.
   3. `POST /api/user/admin` -> Copy admin token.
   4. Paste admin token into Headers (`token: <admin_token>`) to test `/api/product/add` (requires Form-Data).
   5. Use `GET /api/product/list` to fetch products.
   6. Use `POST /api/cart/add` to test inventory handling.

## 10. API Workflow

`User Registration/Login` ↓ `Browse Products (GET /api/product/list)` ↓ `View Product (POST /api/product/single)` ↓ `Upload Design (POST /api/customizer/upload)` ↓ `Add Custom T-Shirt to Cart (POST /api/cart/addStandaloneCustomized)` ↓ `Checkout (POST /api/order/stripe)` ↓ `Verify Payment (POST /api/order/verifyStripe)`
